    📖 CLI Documentation Guide¶

    What's New (Today's Work)¶

    Three essential new documentation files have been added to help users succeed with Shadowforge:

    1. Quick Reference (quick-reference.md)¶

    The go-to cheatsheet for users who know Shadowforge and need fast command lookups.

    Contains: - Most common commands with examples - Distribution patterns quick lookup - Complete flags & options reference - File type and capacity reference tables - Performance tips - Common errors and quick fixes - One-liners and workflows

    Best for: Users who are familiar with Shadowforge and need command syntax quickly.

    2. Troubleshooting Guide (troubleshooting.md)¶

    Organized by problem type - find the issue you're facing and get solutions.

    Covers: - General issues (command not found, permissions) - Embedding problems (insufficient capacity, unsupported formats) - Extraction failures (no data found, corruption) - Distributed operation issues - Archive problems - Performance bottlenecks - Security concerns - System-specific issues (macOS, Linux, Windows)

    Best for: Users experiencing problems who need systematic solutions.

    3. FAQ (faq.md)¶

    50+ common questions answered conversationally with practical tips.

    Sections: - Installation & setup (5 questions) - Basic usage (5 questions) - Distribution patterns (4 questions) - Security (5 questions) - Troubleshooting (5 questions) - Advanced usage (5 questions) - Performance (3 questions) - Legal & compliance (5 questions) - Getting help (escalation paths)

    Best for: Users with specific questions or uncertain about concepts.

    Documentation Reading Paths¶

    Path 1: Getting Started (30 minutes)¶

    1. README.md (2 min)
    2. Installation (5 min)
    3. Getting Started (15 min)
    4. Try first embed command
    5. Try first extract command
    6. Bookmark Quick Reference

    → Result: User can embed and extract secrets

    Path 2: Distribution Master (45 minutes)¶

    1. Start with Path 1
    2. Distribution Patterns guide (15 min)
    3. Try one-to-many example
    4. Review Quick Reference section on distribution
    5. Try your own distribution

    → Result: User can use distributed patterns

    Path 3: Problem Solver (varies)¶

    1. Describe problem to yourself
    2. Find matching section in Troubleshooting
    3. Try first solution
    4. If not working, check FAQ
    5. If still stuck, check full Commands Reference

    → Result: User solves their issue

    Path 4: Security Hardener (30 minutes)¶

    1. Security Best Practices guide
    2. FAQ - Security Questions section
    3. Try encrypted embedding example
    4. Try password-protected distributed
    5. Review key generation

    → Result: User implements security best practices

    Recommended Reading Order¶

    For new users discovering Shadowforge: 1. README.md 2. Getting Started 3. Try an example 4. Bookmark Quick Reference

    When getting stuck: 1. Troubleshooting (find your issue) 2. Try suggested fix 3. If that doesn't work, check FAQ for related concepts
