    Shadowforge¶

    "Forge secrets in the shadows, shield them from quantum eyes"

    Overview¶

    Shadowforge is a production-grade quantum-resistant steganography toolkit that combines:

    • 🔐 Post-Quantum Cryptography (NIST-approved Kyber-1024 & Dilithium3)
    • 🎨 Multi-Technique Steganography (7 techniques across image/audio/text/PDF)
    • 🛡️ Reed-Solomon Error Correction (K-of-N threshold recovery)
    • 📦 Distributed Storage (Split secrets across multiple carriers)

    Quick Start¶

    Installation¶

    brew install greysquirr3l/tap/shadowforge

    git clone https://github.com/greysquirr3l/shadowforge
cd shadowforge
go build -o shadowforge ./cmd/cli

    Basic Usage¶

    # Generate quantum-resistant key pair
shadowforge keygen --algorithm kyber1024 --output keys/

# Embed secret in image
shadowforge embed \
  --input secret.txt \
  --cover image.png \
  --output stego.png \
  --public-key keys/public.key

# Extract secret
shadowforge extract \
  --input stego.png \
  --output recovered.txt \
  --private-key keys/private.key

    Features¶

    Feature Description
    Quantum-Resistant Kyber-1024 key encapsulation, Dilithium3 signatures
    7 Stego Techniques LSB, DCT, Palette, Phase, Echo, LSB-Audio, Zero-Width
    Multiple Media Images (PNG/JPEG/BMP/GIF), Audio (WAV), Text, PDF
    Error Correction Reed-Solomon with 20-50% configurable redundancy
    Distributed One-to-Many, Many-to-One, Many-to-Many patterns
    Cross-Platform macOS, Linux, Windows (single binary)
    Open Source MIT License, community-driven development

    Security First¶

    Shadowforge is built with security as the top priority:

    • ✅ NIST-approved post-quantum cryptography
    • ✅ Constant-time operations to prevent timing attacks
    • ✅ Secure memory handling with key zeroing
    • ✅ Comprehensive input validation
    • ✅ Battle-tested open-source libraries
    • ✅ Regular security audits

    Important Security Notice

    • No software is 100% secure - use defense in depth
    • Always use the latest version
    • Report security issues responsibly via GitHub Security Advisories

    Use Cases¶

    Secure Communication

    Hide encrypted messages in ordinary images or audio files for covert communication channels.

    Document Tracking

    Embed forensic watermarks in PDFs to track document distribution and detect leaks.

    Data Redundancy

    Split backups across multiple media files with error correction for fault-tolerant storage.

    Privacy Protection

    Store sensitive data within innocuous files to avoid detection during searches.
