⚡ Quick Start

Install Shadowforge

brew install greysquirr3l/tap/shadowforge

Embed a Secret in an Image

shadowforge embed --input secret.txt --cover image.png --output stego.png

Extract the Secret

shadowforge extract --input stego.png --output recovered.txt
